# DevOps Lab Mid - Assignment Portal

## How to run the application
1. Run `npm install` to install dependencies.
2. Run `npm start` to start the portal on port 4000.

## How to run the local receiver
1. Run `npm run receiver` to start the receiver on port 5000.
2. The receiver saves reports to `test-report.json`.

## How to execute the tests
1. Run `npm test` to run the automated test suite.
